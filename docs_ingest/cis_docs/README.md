# CIS Security Benchmarks Directory

Place official CIS Benchmark PDF files or custom reference texts in this directory.

## Current Benchmark Reference Material Included
1. **AWS CIS Foundations Benchmark v2.0.0**:
   - Section 2.1.1: Ensure S3 Bucket Access Logging and Public Access Block is Enabled.
   - Section 5.1: Ensure Security Groups do not allow unrestricted ingress (0.0.0.0/0) on sensitive ports.
   - Section 1.16: Ensure IAM Policies do not use wildcard '*' actions on sensitive resources.

2. **Kubernetes CIS Benchmark v1.8.0**:
   - Section 5.2.1: Minimize the admission of root containers (runAsNonRoot: true).
   - Section 5.2.2: Minimize admission of containers with privilege escalation.
